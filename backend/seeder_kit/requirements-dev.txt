# Pinned TEST toolchain for backend/seeder_kit.
#
# Purpose: make the test run reproducible. Today `pyproject.toml` declares its
# dev extra as `pytest>=8.0` (a floor with no ceiling), so two runs a month
# apart can resolve different pytest majors and disagree. This file pins the
# exact set so CI and a contributor's laptop collect and run identically.
#
# SCOPE — test toolchain ONLY. This does NOT pin seeder_kit's runtime
# dependencies, because it deliberately has none: `pyproject.toml` declares
# `dependencies = []` and every optional import (`mcp`, `pyyaml`) is done lazily
# inside the function that needs it. The one optional runtime dep, `mcp>=1.28,<2`
# (the `[mcp]` extra, needed only to run runner.py as a live stdio server), is
# NOT pinned here — see the note at the bottom.
#
# Every version below was read from an actual working environment
# (`backend/wrapper/.venv`, Python 3.11.14) rather than guessed.
#
# Usage:
#   python -m pip install -r requirements-dev.txt
#   python -m pip install -e .
#   python -m pytest
#
# Regenerate after an intentional upgrade:
#   python -m pip install --upgrade pytest && python -m pip freeze
