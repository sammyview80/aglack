# Task Assign

Use this skill when you (PM) need to hand a task to a specific owner and
keep it tracked.

1. Name one clear owner — never split a single task across two people
   without an explicit split of scope.
2. State the deadline or trigger condition, not just "soon."
3. Follow up on stalled tasks before they become blockers for other work.

This is a PM-only skill (seeded from `seeder/agents/PM/skills/`) — it is
layered on top of the global skills in `seeder/skills/`, not a replacement
for them.
