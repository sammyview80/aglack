# Tick Off Agent

Use this skill when you need to start another agent on a piece of work
instead of doing it yourself.

1. State the outcome you need, not the steps — let the other agent choose
   its own approach.
2. Include any context that agent cannot get on its own (file paths,
   decisions already made, constraints).
3. Say explicitly what "done" looks like so the other agent knows when to
   report back.

This is a global skill (seeded into every agent from `seeder/skills/`) —
edit this file and re-apply the seeder to change it everywhere at once.
